# Install 5G Union App on Your Device

The Shanan Gibe Student Union website is now available as an installable app! Get quick access from your home screen and use it offline.

---

## 📱 Install on Android

### **Method 1: Install Banner (Easiest)**
1. Visit https://5gstudentunion.vercel.app on Chrome or Edge
2. Wait a few seconds - an install banner will appear at the bottom
3. Tap **"Install"**
4. The app icon will appear on your home screen
5. Tap the icon to open the app

### **Method 2: Browser Menu**
1. Visit https://5gstudentunion.vercel.app
2. Tap the three dots menu (⋮) in the top right
3. Tap **"Add to Home Screen"** or **"Install app"**
4. Tap **"Install"** or **"Add"**
5. App icon appears on your home screen

---

## 📱 Install on iPhone/iPad

1. Visit https://5gstudentunion.vercel.app in **Safari** (must use Safari, not Chrome)
2. Tap the **Share** button at the bottom of the screen (box with arrow pointing up)
3. Scroll down and tap **"Add to Home Screen"**
4. Edit the name if you want, then tap **"Add"**
5. The app icon will appear on your home screen
6. Tap the icon to open the app

**Note**: On iOS, the app opens in Safari but looks like a native app without the browser bars.

---

## 💻 Install on Desktop (Windows/Mac/Linux)

### **Chrome / Edge / Brave**
1. Visit https://5gstudentunion.vercel.app
2. Look for the install icon in the address bar (⊕ or ⬇ symbol)
3. Click the icon
4. Click **"Install"**
5. The app will open in its own window
6. Find it in your Start Menu (Windows) or Applications folder (Mac)

**Alternative:**
- Click the three dots menu (⋮)
- Select **"Install Shanan Gibe Student Union..."**
- Click **"Install"**

## 🗑️ How to Uninstall

### **Android**
1. Long-press the app icon on your home screen
2. Tap **"Uninstall"** or drag to **"Remove"**
3. Confirm removal

**Alternative:**
- Settings → Apps → Shanan Gibe Student Union → Uninstall

### **iOS**
1. Long-press the app icon on your home screen
2. Tap **"Remove App"**
3. Tap **"Delete App"**
4. Confirm removal

### **Desktop**
**Windows:**
- Settings → Apps → Shanan Gibe Student Union → Uninstall

**Mac:**
- Applications folder → Drag "Shanan Gibe Student Union" to Trash

**Chrome/Edge:**
- Right-click the app icon in your shelf/taskbar → Uninstall

## ❓ Frequently Asked Questions

### **Is this a real app or just a website?**
It's a Progressive Web App (PWA) - a modern website that installs and behaves like a native app. You get the best of both worlds: easy installation without app stores, and app-like experience.

### **Does it take up a lot of space?**
No! It's much smaller than a native app (typically under 10MB). It only caches the pages you visit.

### **Will it work without internet?**
Some features work offline:
- ✅ View previously loaded pages
- ✅ Browse cached content
- ✅ See your profile

You'll need internet for:
- ❌ Login/registration
- ❌ New announcements and events
- ❌ Posting in forums
- ❌ Uploading images

### **Will I get updates automatically?**
Yes! The app checks for updates automatically when you open it. New features and fixes are downloaded in the background.

### **Is it safe?**
Yes! The app:
- Uses the same security as the website (HTTPS)
- Doesn't track you beyond normal website analytics
- Stores only cached pages, no personal data offline
- Can be uninstalled anytime, removing all cached data

### **Does it drain my battery?**
No! It uses less battery than using a regular browser because cached content loads faster and uses less data.

### **Why don't I see the install prompt?**
Possible reasons:
- You already installed it
- You dismissed it recently (wait 30 days)
- Your browser doesn't support PWA installation
- You need to visit the site a few times first

Try the manual browser menu method instead!
